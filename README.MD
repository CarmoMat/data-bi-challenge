# Indicium AI — Desafio Técnico de Data/BI

## Contexto

Desafio técnico de seleção envolvendo um cenário fictício de varejo náutico (LH Nautical), cobrindo o pipeline completo de dados: da ingestão bruta (CSV) até a modelagem em banco relacional, análise exploratória, SQL avançado, previsão de demanda e sistema de recomendação.

## Objetivo

Aplicar conceitos de engenharia e análise de dados em um cenário próximo de um problema real de negócio, passando pelas etapas de preparação, exploração e modelagem dos dados até a geração de análises, previsões e recomendações.

## Tecnologias utilizadas

- **SQL (PostgreSQL)** — modelagem, CTEs, window functions e JOINs
- **Python** — pandas, psycopg2 e scikit-learn
- **Looker Studio** — visualização e dashboard

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `data/` | Arquivos CSV originais fornecidos no desafio |
| `questao1_eda/` | Análise exploratória da tabela `orders` |
| `questao2_schema/` | Script Python de inferência de schema e geração de `schema.sql` |
| `questao3_carregamento/` | Script de carregamento dos CSVs no PostgreSQL |
| `questao4_clientes/` | Análise de clientes fiéis (SQL com CTEs) |
| `questao5_calendario/` | Dimensão de calendário e vendas por dia da semana |
| `questao6_previsao/` | Previsão de demanda com baseline de média móvel |
| `questao7_recomendacao/` | Sistema de recomendação por similaridade de cosseno |
| `dashboard/` | Link e prints do dashboard no Looker Studio |

Cada pasta contém seu próprio `README.md` com a explicação e as respostas da questão correspondente.
